# Skills de Salesforce para Nouter

Un subconjunto de [forcedotcom/sf-skills](https://github.com/forcedotcom/sf-skills): las skills de Salesforce que usa la línea de
entrega de Nouter (el plugin `delivery-salesforce` de [Nouter-ai/plugin-catalog](https://github.com/Nouter-ai/plugin-catalog)).
Es un marketplace (`.claude-plugin/marketplace.json`, nombre `salesforce`): una empresa lo agrega en *Organization → Skills → Add
marketplace* y lo deja en *Installed by default*.

Las skills se copian sin cambios del commit que dice [NOTICE](NOTICE), con su licencia Apache 2.0 ([LICENSE](LICENSE)).
